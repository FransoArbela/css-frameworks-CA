# Project Title

A simple responsive website built as part of the CSS Frameworks course at Noroff. The project focuses on using **Tailwind CSS** for styling and creating a clean, accessible layout across multiple pages.

## Description

This project is a front-end website consisting of three responsive pages and one fake login page. It uses **Tailwind CSS** as the main styling framework to demonstrate utility-first styling principles. The login form includes HTML form input validation to simulate a realistic user experience.

Ai generated content has been used throughout the site to focus on layout and styling rather than actual data.

## Built With

- [Tailwind CSS](https://tailwindcss.com/)
- HTML5

### Installation

1. Clone the repository:
```bash
   git clone https://github.com/FransoArbela/css-frameworks-CA.git
```
2. Navigate to the project directory:

```bash
   cd css-frameworks-CA
```

3. Install dependencies:

```bash
   npm install
```

### Running the project

```bash
npm run dev
```

4. Start the dev server:

```bash
   npm run dev
```

## Usage
